# Light trousers

Models of item 19979 (Light trousers), extracted unchanged from the local OSRS rev 241 cache
(`caches/osrs-241_2026-10-20`, model index 7) as raw, decompressed model files.

- `drop.dat`: inventory / ground model 31992
- `equip.dat`: male wear model 31785
- `equip-female.dat`: female wear model 31857

They are the newer "type 3" model format (files end in `FF FD`), not the old format of
`dragonic-katana`. The item is worn in the legs slot (wearPos 7) and has no recolours,
retextures, resize or wear offsets, and no second wear or head models.

## Blender

Import the `.dat` files with `../io_osrs_dat.py` (File > Import / Export > OSRS model (.dat)),
which also exports back to `.dat`.
